## 🛠️ Tech Stack

| Category | Technologies |
|----------|-------------|
| ⚛️ **Frontend** | React 19, TypeScript |
| ⚡ **Build Tool** | Vite |
| 🎨 **Styling** | Tailwind CSS v4 |
| 🎞️ **Animation** | GSAP, Motion (Framer Motion) |
| 🗃️ **State Management** | Zustand |
| 📄 **PDF Viewer** | React PDF |
| 📝 **Markdown Renderer** | React Markdown, remark-gfm |
| 🔍 **Icons** | Lucide React |
| 🧩 **UI Primitives** | Base UI, Shadcn |

## 🚀 Getting Started

Clone the repo and run it locally in just a few steps:

```bash
# 1. Clone the repository
git clone https://github.com/OthmaneEr-Refaly/Macos-Portfolio.git

# 2. Navigate into the project
cd Macos-Portfolio

# 3. Install dependencies
npm install

# 4. Start the dev server
npm run dev
```

Then open [http://localhost:5173](http://localhost:5173) in your browser.
